Getting started

Riot Office is a desktop office suite that runs entirely on your PC. It is built on LibreOffice and set up to feel like the Office you know:

You knowOpenSaves by default as
WordRiot Writer.docx
ExcelRiot Calc.xlsx
PowerPointRiot Impress.pptx
AcrobatPDF tools in the Riot Office window.pdf

Start Riot Office from the Start menu (Windows) or the applications menu (Ubuntu) and click Writer, Calc or Impress, or Open a file. Double-clicking a .docx, .xlsx or .pptx file opens it directly.

The toolbar is the tabbed one (File, Home, Insert, Layout, ...). If you prefer classic menus and toolbars: View → User Interface → Standard Toolbar.

Language

Riot Office speaks English and Italian. Use the Language menu (Lingua) of the Riot Office window: the window changes at once, LibreOffice changes the next time it starts (close its windows first). Spelling is checked in English and Italian; set a document's language from Tools → Language.

OCR — Ubuntu: sudo apt install ocrmypdf tesseract-ocr-ita tesseract-ocr-eng. Windows: install Tesseract with winget install -e --id tesseract-ocr.tesseract (add the Italian language during setup) and OCRmyPDF with pip install ocrmypdf.

To view or annotate a PDF, open it with LibreOffice Draw or your usual viewer. A full PDF editor with Italian digital signatures is on the roadmap.

For Excel users

Calc handles formulas, pivot tables, filters, charts and the modern functions (XLOOKUP, FILTER, SORT, UNIQUE, LET, dynamic arrays). Not available: Power Query (queries can't be refreshed), Power Pivot / Data Model, slicers. LAMBDA arrives with LibreOffice 27.2. VBA macros run only in part.

Riot Office adds GROUPBY, PIVOTBY, PERCENTOF, REGEXTEST, REGEXEXTRACT and REGEXREPLACE to Calc (category Add-In). They work when typed in Calc and are saved in .ods; in .xlsx they show #NAME? when the file is reopened, so keep such workbooks as .ods. Aggregations are given by name: =GROUPBY(A1:A6; C1:C6; "SUM"). Full reference in EXCEL-FUNCTIONS.md. Details in COMPATIBILITY.md.

Moving from Microsoft Office

1. Find the files that need attention

riot-office inventory "D:\Shared" --out inventory.md --csv inventory.csv

Nothing is opened or run: the report lists macros, Power Query, data models, slicers, functions Calc lacks, the Aptos font, SmartArt and encrypted files.

2. Measure how close the result is

Copy a few hundred typical documents into a folder. Export each one to PDF from Microsoft Office into a second folder with the same names. Then:

riot-office fidelity corpus office-pdfs --out fidelity.md

Each document gets the page count in Office and in Riot Office and a text similarity score; it passes with the same page count and at least 0.95 similarity.

Command line

riot-office                          the window
riot-office addin install|uninstall|status   the Excel functions for Calc
riot-office doctor                   check LibreOffice, configuration, fonts, OCR
riot-office open writer|calc|impress [files]
riot-office convert FILES --to pdf [--pdfa] [--out FOLDER]
riot-office pdf merge OUT IN...
riot-office pdf split IN [--ranges 1-3,4-10] [--out FOLDER]
riot-office pdf rotate IN OUT --degrees 90 [--pages 1,3-5]
riot-office pdf ocr IN OUT [--lang ita+eng]
riot-office inventory FOLDER [--out report.md] [--csv report.csv]
riot-office fidelity CORPUS REFERENCES [--out report.md]
riot-office language en|it
riot-office config install|uninstall|status

On Windows the command is "C:\Program Files\Riot Office\runtime\python.exe" -m riot_office.

For IT

  • Windows silent install: RiotOffice-Setup-<version>.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /LANG=it. LibreOffice is installed per machine with UI_LANGS=en_US,it, Office file types registered, no update check.
  • Ubuntu: sudo apt install ./riot-office_<version>_all.deb, or publish it in an internal APT repository.
  • The configuration is four small files, riot-office*.xcd, in <LibreOffice>\share\registry\ on Windows and /etc/libreoffice/registry/ on Ubuntu. Defaults, not locks. To enforce settings on Windows use Group Policy under HKLM\Software\Policies\LibreOffice.
  • Updates: install newer LibreOffice point releases promptly — they fix bugs that malicious documents can trigger.

Troubleshooting

ProblemSolution
The window says LibreOffice was not foundRun the setup again (Windows) or sudo apt install libreoffice-writer libreoffice-calc libreoffice-impress.
"The Riot configuration is not installed"Windows: run the setup again. Ubuntu: sudo apt install --reinstall riot-office.
LibreOffice is still in the old languageClose every LibreOffice window, including the one in the system tray, and open it again.
